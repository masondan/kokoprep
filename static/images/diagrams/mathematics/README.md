# Mathematics Diagram Images

Place diagram PNG images for mathematics questions here.

## Naming Convention
Use descriptive, lowercase, hyphenated filenames matching the `imagePath` value in `mathematics.json`.

## Examples
- `angles_straight_line.png`
- `angles_triangle.png`
- `shaded_fraction.png`

## JSON Reference
In `src/lib/data/questions/mathematics.json`, reference images like:
```json
"imagePath": "/images/diagrams/mathematics/angles_straight_line.png"
```

Note the leading `/` — images are served from the `static/` folder root.
