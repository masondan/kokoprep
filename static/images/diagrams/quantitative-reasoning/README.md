# Quantitative Reasoning Diagram Images

Place diagram PNG images for quantitative reasoning questions here.

## Naming Convention
Use descriptive, lowercase, hyphenated filenames matching the `imagePath` value in the relevant JSON file.

## Examples
- `quant_sample.png` — the reference/sample pattern diagram
- `quant_q1.png`, `quant_q2.png` — individual question diagrams

## JSON Reference
Questions with a shared reference pattern use two fields:
```json
"sampleImagePath": "/images/diagrams/quantitative-reasoning/quant_sample.png",
"imagePath": "/images/diagrams/quantitative-reasoning/quant_q1.png"
```

Note the leading `/` — images are served from the `static/` folder root.
